GameBazaar — серверная часть (Firebase)

В архиве 8 файлов. Все их нужно загрузить в репозиторий:
1. firebase-config.js  — ключи твоей базы (уже вписаны)
2. auth.js             — регистрация и вход
3. index.html          — главная (витрина лотов)
4. login.html          — вход/регистрация
5. chat.html           — чат поддержки для пользователей
6. admin.html          — админ-панель (обращения, транзакции, пользователи)
7. style.css           — стили
8. README.txt          — этот файл

Загрузка: GitHub -> репозиторий -> кнопка "+" -> Upload files ->
перетащить ВСЕ файлы -> согласиться на замену -> Commit changes.
Потом на сайте: Ctrl+Shift+R.
